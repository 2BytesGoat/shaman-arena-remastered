# Shaman Arena Remastered

A fast arcade local PvP game about shamans throwing spells at each other — a
Godot 4.6 remaster of our Global Game Jam 2026 entry.

## Repository layout

- `godot/` — the Godot project (open this folder in the editor)
- `docs/` — design and planning notes
- `.github/workflows/test.yml` — CI, runs the gdUnit4 test suite with headless Godot
